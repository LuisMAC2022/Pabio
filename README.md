# Pabio - Automatizacion de ordenes de mantenimiento

## Descripcion
En este repositorio se esta desarrollando el sistema de automatizacion de ordenes de mantenimiento. 
El proposito es:
1) Generar ordenes de manera rapida y sencilla
2) Realizar un analisis de riesgo para determinar prioridad
3) Contrastar los insumos necesarios para cumplir el pedido con los materiales en inventario
4) Generar la solicitud unica de compra cuando sea necesaria
5) Otorgar un estimado de tiempo para cumplir la orden que pueda ser consultado por el usuario
6) Dar trazabilidad a todo el proceso

## Flujo rápido
1. Crear orden.
2. Revisar órdenes.
3. Ajustar inventario.
4. Contrastar y generar solicitud de compra.
5. Cumplimiento de orden.
